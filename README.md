# 🧠 Atividade Prática 07 — Escola da Nuvem

Este repositório contém os códigos desenvolvidos para a Atividade Prática 07, proposta nos slides da Aula 11 da Escola da Nuvem. Os exercícios exploram manipulação de arquivos em Python, com foco em leitura e escrita de dados nos formatos CSV e JSON, além de cálculos estatísticos simples com uso de bibliotecas como `pandas`.

---

## 📋 Exercícios

### 1️⃣ Escrita de Dados em CSV  
**Descrição:** Um script que recebe informações pessoais (Nome, Idade e Cidade) e grava os dados em um arquivo CSV utilizando a biblioteca `pandas`.

### 2️⃣ Leitura de Dados de um Arquivo CSV  
**Descrição:** Um script que lê um arquivo CSV contendo informações de pessoas e exibe os dados formatados na tela.

### 3️⃣ Leitura e Escrita de Dados em JSON  
**Descrição:** Um script que grava informações de uma pessoa (nome, idade e cidade) em um arquivo JSON e, em seguida, lê e exibe os dados salvos.

### 4️⃣ Análise de Log de Treinamento de Modelos de Machine Learning  
**Descrição:** Um script que lê um arquivo CSV contendo tempos de execução de treinamentos e calcula a média e o desvio padrão desses tempos utilizando `pandas`.

---
