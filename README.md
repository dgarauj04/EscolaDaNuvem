# 🧮 Atividade Prática 02 – Escola da Nuvem

Este repositório contém os códigos desenvolvidos para a **Atividade Prática 02**, que inclui seis pequenos programas em Python com foco em lógica de programação e manipulação de dados básicos.

---

## 📌 Lista de Exercícios

### 1. Conversor de Moeda
Converte um valor em reais para dólares e euros com base em taxas fixas.

- **Entrada:** R$ 100.00
- **Taxas:** Dólar = R$ 5.60 | Euro = R$ 6.60
- **Saída:** Valores convertidos com duas casas decimais.

### 2. Calculadora de Desconto
Calcula o valor do desconto e o preço final de um produto.

- **Produto:** Camiseta
- **Preço original:** R$ 50.00
- **Desconto:** 20%
- **Saída:** Valor do desconto e preço final.

### 3. Calculadora de Média Escolar
Calcula a média de três notas escolares.

- **Notas:** 7.5, 8.0, 6.5
- **Saída:** Média final com duas casas decimais.

### 4. Calculadora de Consumo de Combustível
Calcula o consumo médio de um veículo.

- **Distância:** 300 km
- **Combustível gasto:** 25 litros
- **Saída:** Consumo médio (km/l).

### 5. Calculadora de Soma com Entrada do Usuário
Lê dois valores inteiros e imprime a soma formatada.

- **Entrada:** A e B (inteiros)
- **Saída:** `X = resultado`

### 6. Calculadora de Salário por Horas Trabalhadas
Calcula o salário de um funcionário com base nas horas trabalhadas.

- **Entrada:** Número do funcionário, horas trabalhadas, valor por hora
- **Saída:** `Número do funcionário = X`  
  `Salário = R$ Y.YY`

1. Clone o repositório:
   ```bash

   ```

2.Acesse a pasta:

cd EscolaDaNuvem-atividade02

3.Execute os arquivos Python individualmente:

python soma.py
