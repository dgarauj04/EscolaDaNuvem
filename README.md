# 🧠 Atividade Prática 03 — Escola da Nuvem

Este repositório contém os códigos desenvolvidos para a Atividade Prática 03, proposta pela Escola da Nuvem. Os exercícios abordam conceitos fundamentais de programação como entrada e saída de dados, estruturas condicionais, cálculos matemáticos e formatação de resultados.

---

## 📋 Exercícios

### 1️⃣ Área da Circunferência  
**Descrição:** Calcula a área de uma circunferência com base no raio informado.  
**Fórmula:** área = π × raio² (π = 3.14159265)  
**Conceitos:** Operações com ponto flutuante, formatação com 4 casas decimais.

### 2️⃣ Classificador de Idade  
**Descrição:** Classifica a idade do usuário em uma das categorias: Criança, Adolescente, Adulto ou Idoso.  
**Conceitos:** Estruturas condicionais, entrada de dados.

### 3️⃣ Calculadora de IMC  
**Descrição:** Calcula o Índice de Massa Corporal (IMC) e exibe a classificação correspondente.  
**Conceitos:** Operações matemáticas, lógica condicional, entrada de dados.

### 4️⃣ Conversor de Temperatura  
**Descrição:** Converte temperaturas entre Celsius, Fahrenheit e Kelvin.  
**Conceitos:** Condicionais múltiplas, entrada de dados, conversão de unidades.

### 5️⃣ Verificador de Ano Bissexto  
**Descrição:** Verifica se um ano informado é bissexto com base nas regras do calendário gregoriano.  
**Conceitos:** Módulo, lógica booleana, entrada de dados.

### 6️⃣ Calculadora de Comissão  
**Descrição:** Calcula o salário total de um vendedor com base no salário fixo e nas vendas realizadas (com 15% de comissão).  
**Conceitos:** Operações com ponto flutuante, formatação com 2 casas decimais.

### 7️⃣ Calculadora da Média  
**Descrição:** Calcula a média ponderada de quatro notas e determina a situação do aluno (aprovado, reprovado ou em exame).  
**Conceitos:** Média ponderada, estruturas condicionais aninhadas, entrada e saída formatada.
