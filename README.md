# 🧠 Atividade Prática 01 — Escola da Nuvem

Este repositório contém os códigos desenvolvidos para a **Atividade Prática 01**, proposta pela *Escola da Nuvem* Os exercícios abordam conceitos básicos de programação como entrada e saída de dados, operações matemáticas e manipulação de variáveis.

---

## 📋 Exercícios

### 1️⃣ Programa de Saudação
- **Descrição:** Imprime a mensagem `"Hello, world!"` na tela.
- **Conceitos:** Saída de texto simples.

### 2️⃣ Calculadora de Soma
- **Descrição:** Soma dois números inteiros (`numero1 = 12`, `numero2 = 14`) e exibe o resultado.
- **Conceitos:** Operações aritméticas, variáveis.

### 3️⃣ Calculadora de Volume
- **Descrição:** Calcula o volume de uma caixa retangular com dimensões:
  - Comprimento: 12 cm
  - Largura: 14 cm
  - Altura: 20 cm
- **Fórmula:** `volume = comprimento * largura * altura`
- **Resultado:** Volume em cm³.
- **Conceitos:** Multiplicação, unidades de medida.

### 4️⃣ Calculadora de Preço Total
- **Descrição:** Calcula o preço total da compra de 3 unidades do produto `"Cadeira Infantil"` com preço unitário de `R$ 12.40`.
- **Conceitos:** Multiplicação, exibição de informações formatadas.

### 5️⃣ Calculadora de Número Inteiro
- **Descrição:** Lê quatro valores inteiros `A`, `B`, `C`, `D` e calcula a diferença entre os produtos:
DIFERENCA = (A * B - C * D)
- **Entrada:** 4 números inteiros
- **Saída:** Mensagem `"DIFERENCA = "` seguida do valor calculado, em letras maiúsculas.
- **Conceitos:** Entrada de dados, operações compostas, formatação de saída.
