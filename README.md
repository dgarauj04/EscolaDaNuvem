# 🧠 Atividade Prática 04 — Escola da Nuvem

Este repositório contém os códigos desenvolvidos para a Atividade Prática 04, proposta pela Escola da Nuvem. Os exercícios abordam conceitos essenciais de programação como validação de entrada, tratamento de exceções, estruturas de repetição e lógica condicional.

---

## 📋 Exercícios

### 1️⃣ Calculadora com Tratamento de Erros
**Descrição:** Solicita dois números e uma operação (+, -, *, /). Realiza o cálculo e trata erros como entrada inválida, operação inválida e divisão por zero. 
**Conceitos:** try/except, validação de entrada, operadores aritméticos, controle de fluxo.

### 2️⃣ Registro de Notas da Turma
**Descrição:** Permite ao professor inserir notas entre 0 e 10 até digitar 'fim'. Ignora entradas inválidas e calcula a média da turma. 
**Conceitos:** Laço while, validação de intervalo, conversão de tipos, cálculo de média.

### 3️⃣ Verificador de Senha Forte
**Descrição:** Solicita senhas até que uma válida seja inserida ou o usuário digite 'sair'. A senha deve ter pelo menos 8 caracteres e conter ao menos um número. 
**Conceitos:** Validação de string, uso de any() e isdigit(), controle de repetição.

### 4️⃣ Classificador de Números Pares e Ímpares
**Descrição:** Solicita números inteiros até que o usuário digite 'fim'. Informa se cada número é par ou ímpar e exibe o total de cada categoria. 
**Conceitos:** try/except, operadores de módulo, contadores, validação de tipo.
